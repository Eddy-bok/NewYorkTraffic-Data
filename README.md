## 📊 Project Description

### 1. **NewYork_Crashes.ipynb**
Explores motor vehicle collision data using Python. Key analyses include:
- Trend analysis by borough and time
- Pedestrian and cyclist safety insights
- Heatmaps of collision density
- Recommendations based on findings

### 2. **Scientific Research Poster**
A visually summarized version of the analysis suitable for academic presentation. It communicates key insights, visualizations, and conclusions.
